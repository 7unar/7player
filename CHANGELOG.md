## [0.1.0] - 2026-11-08

### Added

- NetEase Cloud Music TUI for Linux and WSL, built with Ratatui, Crossterm and Rodio.
- QR-code and phone/password login, persisted cookies and anonymous sessions.
- Search, public charts, daily recommendations, playlists and queue playback.
- Synced LRC lyrics with translations and an immersive pure-lyrics screen.
- Ten built-in themes, including Tokyo Night, Catppuccin, Dracula, Nord and Gruvbox.
- Configurable normal-mode keymap plus Vim-style navigation and mouse support.
- Braille signature splash screen at 60 fps.
- Auto-routing to WSLg PulseAudio, silent fallback when no audio device is available.
- Headless `--check` network/API self-test and 44 unit tests.
- GitHub Actions CI and a tagged-release workflow for Linux x86_64.
